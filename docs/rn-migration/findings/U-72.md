## 2. Findings

1. **No analyzing checklist, no dwell timer.** The Ember analyzing frame has no step list. The model no longer plays
   steps with a 0.5 s dwell or a 5 s watchdog: a response lands in review the moment the call settles. `AnalyzingStep`
   is removed. Swift's dwell and fourth step are dropped on purpose.
2. **`captureCorrection` still clears "Review needed"** (as in Swift). The owner wrote "reporting does not change the
   diary entry". That holds for the entry, but a report also lifts the Save gate on an unresolved item. If a report
   should not lift the gate, the user must remove the item or fix it first. **Decision for the owner.**
3. **Report a problem sends nothing.** The contract has no report endpoint. The sent state therefore says "Thanks,
   report noted" and "Your review hasn't changed: to fix this meal now, edit the item". The "Include the photo"
   toggle (off by default) is stored on the correction (`includePhoto`) and goes nowhere.
4. **Per-item entry point.** "Report a problem" is a link on each item card (`scan.fixIssue.<id>`), not a dock note
   row. The sheet has item pills to retarget, direct fixes first (Wrong amount opens the grams editor, Shouldn't be
   here removes the item), then the note.
5. **The Saved screen replaces the toast and the peek.** Undo, Scan another and View diary live on it; ED-Safe shows the
   dish without kcal and drops the Today card.
6. **Warning chip replaced** by a per-item "includes hidden fat" line (`scan.hiddenFat.<id>`).
7. **Model additions.** `mealMacros()` (whole grams from current grams), an `isUndoing` guard so a second undo while
   one runs tombstones each entry once, `captureCorrection(kind, note, itemId, {includePhoto})`,
   `removeItem`. Displayed kcal is still recomputed from current grams (I6).

## 3. Deviations from the frames (things Stage A does not build)

- **Flash button** (viewfinder): the capture seam has no torch.
- **Free-scans chip and the Describe free-scans line**: not drawn until the server sends the limit (follow-up).
- **Zoom readout** and `scan.zoom`: removed; flip and library are 44 and 52 pt.
- **Describe quick-add chips** (+ Amount / + How it was cooked / + Brand): behavior not specified.
- **Describe estimating "step 2 of 3" checklist**: the server sends no step signal.
- **Describe meal segment** is shown in the typing state too (the frame shows it only while estimating).
- **Describe header search icon** dropped: "Search manually" is reachable only from the error card.
- **Describe chip** on the viewfinder opens text mode; the sheet's X returns to the camera.
- **Report: "Fix it now: rename the item" and "Rename X"**: not built (no rename edit in the model).
- **Report: `missingItem` kind** dropped ("Add a missing item" is Stage A2); kinds `notEaten` and `nutritionOff` added.
- **Review: one-tap answers and serving chips**: the contract has no candidates or servings.
- **Review: ED-Safe note** drops the frame's first line "A balanced plate: protein, carbs and veg."
- **Review: "N items · tap grams to type"** is shown in all schemes.
- **Meal label** is "Snack" (Swift says "Snacks").
- **Glass** is native on iOS 26 and a translucent fill below; no blur package.
