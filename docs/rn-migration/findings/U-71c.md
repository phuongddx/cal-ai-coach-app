## 2. High Contrast: the API names differ from the brief

The brief names `AccessibilityInfo.isHighContrastEnabled()` and the event `highContrastChanged`. **Neither exists in
React Native 0.88.1** (checked in `node_modules/react-native/types_generated/Libraries/Components/AccessibilityInfo/AccessibilityInfo.d.ts`
and `.../AccessibilityInfo.js`). The iOS setting "Increase Contrast" is `isDarkerSystemColorsEnabled()` with the event
`darkerSystemColorsChanged` (iOS only). The code and the test double use those names. On Android and when a native build cannot answer
(the promise rejects) the hook reports normal contrast.

## 3. Light / dark values that moved

Compared with `tokens.ts` on main (`812e926`) for every key of `lightColors` and `darkColors`, and with `git diff origin/main...HEAD -- docs/design/ember/tokens.css`:

- **No existing light or dark value moved.** tokens.css only adds lines to `:root` and `.dark`, plus the `.hc` and `.dark.hc` blocks.
- **Four keys are new** in light and dark: `fillElevated` (`#EFEDEA` / `#3A3632`), `segmentSelected` (`#FFFFFF` / `#3A3632`),
  `onMedia` (`#FFFFFF` / `#FFFFFF`), `mediaScrim` (`rgba(0,0,0,.45)` both).
- **String form of six alpha colors changed, not the color:** `border`, `separator` and `grabber`, light and dark, were `rgba(r,g,b,0.08)` and are
  now `rgba(r,g,b,.08)` (as written in tokens.css). `withAlpha` handles both. A test that compares one of these three to a literal
  `'rgba(20,18,16,0.08)'` must use the token instead; none in this branch did (full suite green).
- **Components whose drawn color moved** (their value, not their token): Segment selected pill dark `text` at 12% -> `#3A3632`
  (light stays `#FFFFFF`); GlassIconButton `overMedia` background `bg` at 45% -> `rgba(0,0,0,.45)` in both schemes, glyph `#F7F5F2` -> `#FFFFFF`.
- **High Contrast** (new, only while Increase Contrast is on) moves: `onAccent`, `accentStrong`, `accentInk`, `ember`, `emberTrack`,
  `emberAccent`, `text`, `text2`, `text3` in light, and `onAccent`, `accentStrong`, `accentInk`, `ember`, `emberTrack`, `emberAccent`, `text`,
  `text2`, `text3` in dark. Others keep the base value (tokens.css says so).
