## 1. ED-safe screen for free text (Toast message, FoodRow chip)

- `carriesCalorieFigure` (Toast.tsx) used to need a digit right before cal / kcal / kJ, so "Calories today: 1,850" and
  "Calories: 640" were shown under ED-safe. Now it is true when the text holds the word `kcal`, `cal`, `calorie`, `calories` or `kJ`
  (word boundary, any case, whatever comes before) or a number followed by one of them (`640kcal`, `2,400kJ`).
- `FoodRow` had no screen on `chip`. It now runs the same rule through the new pure `foodRowVisibleChip(chip, edSafeMode)`; the chip and its
  testID are not drawn at all when it is hidden. `foodRowVisibleChip` is exported from `FoodRow.tsx` only (the barrel is not in this unit's scope).
- Six cases of the brief are tests for both components: "Calories today: 1,850", "640 kcal", "kJ" hidden under ED-safe; "Changes saved",
  "Chicken · 180 g", "Edited" shown. Written first: on the old `Toast.tsx` two of them fail, on the new code all pass.
- Known cost of "conservative": a message that contains the word "Cal" as a name, or "cal" as a word, is hidden under ED-safe too. A hidden
  line is the safe direction; "Calm bowl" still shows (word boundary).
- Caller check: no feature passes a calorie text in `chip`; `Toast.message` callers are unchanged.

## 2. Size variables of the token test are derived

`SIZE_VARIABLES` (an eleven-name regex) is replaced by `isSizeVariable(name, value)`: a variable of `tokens.css` whose value is a bare px length
and that no other group claims (`--s<n>` space, `--r-*` radius, `--t-*` text style). Links 1 and 3 read the group through it, so a new px variable
is a size and must exist in `tokens.json` and `tokens.ts`. Two tests: the derived set is exactly the eleven known variables and equals the keys of
`json.size`; a copy of `tokens.css` with `--ring-xs: 30px` and no counterpart fails link 1 (`json size ringXs`) and link 3 (`tokens size.ringXs differs`),
while the real file still passes. Not covered by design: a new non-px length (rem, %) is not a size and would need its own group.
