## 2. Deviations from the brief and the frames (decide, or tell me to change)

1. **`colors.error`, not `errorInk`.** The brief names `errorInk`; frames 110 and 114 draw the `error` token (#E5243B). The code uses
   `colors.error` for the error border and ring. One line to change if the owner wants `errorInk`.
2. **CodeField gap between the two groups is 20 (`space.xl`)**, the frame is 18. 18 is not a token; 20 is the nearest.
3. **FillField box stays 56 pt** (frame 108 is 52). 56 is the height the component has on main; changing it moves every caller's field, so it is left for the
   owner to decide.
4. **SecondaryButton radius stays `radius.btn` (18).**
5. **No `autoFocus` prop on CodeField.** U-77b will probably want it on the code screen; it is a one-line addition, not made
   because it is not in the nine items.
6. RN 0.88.1 has no `StyleSheet.absoluteFillObject` (undefined). FillField's ring and CodeField's hidden input use explicit
   absolute styles. A test guards the ring.

**This is not "no conflict under `apps/mobile/src/design`", and it is not caused by this unit.** The same command with
`origin/main` instead of `HEAD` gives the same two files, one marker each:

```
$ git merge-tree --write-tree --name-only origin/main origin/rn/u-72-scan-ember
b8db04a5690c6623d1e6739b5c49954ce6fb2d56
apps/mobile/src/design/components/GlassIconButton.test.tsx
apps/mobile/src/design/components/GlassIconButton.tsx
```

Cause: main (U-71c/d) gave `GlassIconButton` the `disabled` prop and `glassDisabledGlyphAlpha`; U-72 rewrote the same lines for the
native glass (D14). Two different edits to the same lines cannot merge by themselves, and resolving them means choosing how
`disabled` looks on a native glass button, which is U-72's decision. This unit adds only the `accessibilityValueText` lines, which
sit in hunks that were already conflicting, so the conflict set is the same before and after. Every other design file
(`EdSafeAlternate`, `SheetHeader`, `ConfidenceBadge`, `index.ts`) merges cleanly, because U-72's copies are byte-identical.

For U-72 when it merges main: keep main's `disabled`/`glassDisabledGlyphAlpha` and U-72's glass, and keep this unit's
`accessibilityValueText` prop and its test ("carries an optional accessibility value and none by default").
