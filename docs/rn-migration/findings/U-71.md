## 5. Added acceptance line: four-digit remaining never wraps in the ring

Source: the Simulator showed "1607" as "16" over "07" in the 140 pt ring (Worker-S2, U-33; their fix
is not on main, so it was rebuilt here).

- `ScaledNumber` takes `fitWidth`; when set it spreads `numberOfLines: 1`, `adjustsFontSizeToFit: true`,
  `minimumFontScale: 0.5` (`fitWidthMinimumFontScale`).
- `CalorieRing` passes `remainingNumberProps = { role: 'hero', fitWidth: true }`; its center view fills the
  ring with `paddingHorizontal = stroke + space.sm`, so the line has a bounded width to shrink to.
- Unit tests assert the props `ScaledNumber` receives and the center container padding
  (`ScaledNumber.test.tsx`, `CalorieRing.test.tsx`).
- **Jest cannot measure text wrapping.** The props are asserted, the rendering is not. **U-76 (the unit
  that holds the Simulator slot) verifies it**: a four-digit remaining value (1607) in the 184 pt hero
  ring and the 120 pt compact ring on the Simulator, one line, shrunk to fit.

## 8. Open questions and notes for CoachCal

1. **SecondaryButton `onPress` required.** The real prop is `action`. It stays optional because
   `features/profile/SettingsDetailView.tsx` (forbidden to this unit) renders two SecondaryButtons
   without an action. Without one the button is exposed as `accessibilityState.disabled`. Recommend
   making `action` required in the Profile restyle unit, which can fix that screen at the same time.
2. **Label "remaining" vs the frame's "kcal left".** Kept "remaining": an existing test asserts it and
   copy is not a token. Frame 07 shows "816 / kcal left"; decide in the Today restyle unit.
3. **`docs/design/ember/frames/*.png` are not in this worktree.** The frames table of the README and
   `index.html` anchors were used; pixel comparison against PNGs is not done.
4. `CalorieRing` defaults to the plain card look; the Ember hero look is `onEmber`, to be used inside
   `EmberCard` by the Today unit.
5. Native sheet detents belong to the route (`sheetAllowedDetents`), not to a view.
