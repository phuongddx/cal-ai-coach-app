## 1. Layout defects seen on the Simulator (fixed here)

- **Bottom inset.** The list runs `contentInsetAdjustmentBehavior="never"` under the native tab bar, so the Swift
  48pt gap (CCSpace.xl5) alone left the last meal row under the bar. `todayBottomPadding(safeAreaBottom)` now stacks the
  safe area, the Scan button offset (28) and height (56), then the 48pt gap. Commit `fix(rn): clear the tab bar…`.
- **Ring number wrap.** Four-digit remaining values wrapped (`1607` → `16` / `07`) inside the 140pt hero ring.
  `ScaledNumber` gets an optional `fitWidth` (one line, shrunk to fit) used by `CalorieRing`. This touches the design
  system (outside `features/today`), so it is its own commit and can be dropped if the Ember restyle replaces it.

## 2. Flow 04 — the blank diary sheet (root cause found, fix in its own commit)

What was seen: `coachcal://diary` opened the diary route as a formSheet that rendered **blank** (grabber visible, no
content), while the same view worked in Jest. Cause: react-native-screens' formSheet layout path for "a ScrollView as
the child" expects at most 2 subviews, and the day view adds the ScrollView plus two Modals as siblings (3). A plain
wrapper `View` is flattened away by Fabric, so the ScrollView stayed the direct child. Fix in `src/app/diary.tsx`:
wrap `DiaryDayView` in `<View style={{ flex: 1 }} collapsable={false}>`. After it flow 04 passed and the diary sheet
showed the day. This file belongs to U-32/U-52, so the fix is a separate commit (`fix(rn): wrap the diary day view…`)
for the owner to keep or drop; the patch is also at the worker's log folder (`diary-sheet-fix.patch`).
