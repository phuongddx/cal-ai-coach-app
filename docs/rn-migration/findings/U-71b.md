## 2. Findings

1. **No blur package, so the glass is translucent fills.** `GlassIconButton` uses `withAlpha` over tokens: `overMedia`
   is `bg` at 45% (the canvas `rgba(0,0,0,.45)`) with an `emberText` glyph; `onSurface` is `card` at 78% in light
   and `text` at 10% in dark, plus a `border` hairline. The canvas `backdrop-filter` blur is not drawn. A blurred
   look needs a blur package (rule 4), which is a decision for the owner.
2. **Two canvas colors have no token.** The dark `.seg` selected pill (`#45403B`) is drawn as `text` at 12% in dark
   and `card` in light; the `overMedia` glyph is `emberText` (`#F7F5F2`), not pure white. If the owner wants exact
   values, `tokens.ts` needs a new key (out of scope here).
3. **`OptionCard` already had a required SF-symbol `icon` and an SF checkmark.** The brief's "icon tile and selected
   check" is delivered as the optional `iconName` prop: with it the 48 pt tile draws `Icon` and the selected check
   is a 22 pt accent circle holding `Icon check` (testID `option-card:<title>:check`). Without it nothing changes.
   Every caller on main compiles and renders as before; no existing assertion was edited.
4. **`Segment` sizes.** Every option is a 44 pt radio. The visible `chips` chip is 36 pt and the `text` pill 34 pt
   inside the 44 pt target, and the `text` track is 44 pt tall where the canvas draws 40 pt: the touch target
   rule wins over the canvas by 4 pt.
5. **`FillField` width.** The input is sized from the character count (13 pt per digit, scaled by font scale up to
   1.3, max 80%) so the unit sits right after the value, as in the frame. This heuristic is not measured.
6. **`GramsRuler` is a responder drag, not a gesture-handler one** (as `PaceSlider`): 1 pt per unit, a minor tick
   every 10 units, a major tick (and label) every `majorEvery`. Dragging right lowers the value. The edge fade is
   an opacity ramp on ticks because React Native has no mask. VoiceOver and TalkBack use the `adjustable` role with
   increment / decrement actions by `step`.
7. **`Icon` fidelity.** Path data and shape attributes are copied from `index.html` verbatim and compared by test
   (51 names, in canvas order, every attribute). `moonsun` keeps its `currentColor` fill, mapped to the icon color.
8. **ED-safe.** Only `EdSafeNote` branches (renders nothing while the mode is off); the branch lives in design (rule 20).
9. **Tokens only.** `grep -rnE "#[0-9A-Fa-f]{6}" apps/mobile/src/design/components` prints nothing.
