## What to build

1. **The port in one place.** `lib.sh` builds the URL of the development client from `METRO_PORT`
   (default 8081), so a session on another port reaches its own Metro. Nothing else of `lib.sh`
   changes for a session that sets no variable: a run with the defaults behaves as today.
2. **A device by name.** `scripts/rn/sim-udid.sh` reads `SIM_NAME` (default `iPhone 17 Pro`) and
   finds the first available device of that name on iOS 26.4. A new script
   `scripts/rn/sim-second.sh` creates the second device once (name `iPhone 17 Pro 2`, the same
   device type and runtime as the first: the type and runtime ids are in the header of
   `sim-udid.sh`) when it does not exist yet, and prints its UDID. It never touches the first
   device.
3. **Nothing touches the other session.** grep the harness and the flows for `shutdown all`,
   `erase all`, `booted` without a UDID, `xcrun simctl kill` and `simctl delete` without a UDID:
   a session shuts down, erases, installs on and launches only its own `$UDID`. Fix what you find
   under `scripts/rn/evidence/**` and list it.
4. **The recipe in the standing orders' table of places** is the owner's to write; you give her
   the two lines of environment a second session exports (`SIM_UDID`, `METRO_PORT`) and what a
   brief must say.
