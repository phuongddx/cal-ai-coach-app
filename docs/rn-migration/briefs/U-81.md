## The defect

On a fresh install, with no stored target, the gate decides `onboarding`, but the Simulator shows
only the Debug route. No onboarding screen, no Today. A user who installs the app never sees
onboarding. The Jest tests of U-51 check the route the gate decides, never the screen the navigator
shows. U-79 could run its flows only through a seeding workaround in
`scripts/rn/evidence/lib.sh` (`_seed_fresh_target`), marked temporary.
