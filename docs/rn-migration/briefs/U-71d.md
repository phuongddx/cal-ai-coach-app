   the way `OptionCard` does.
2. **`InsightCard`** gains two optional props: `iconName`, and an action row slot `action` with

   least 44 pt.

   exist. The custom food sheet of the diary uses it for its "Advanced" group.
6. **`TrendChart`**, new: the weight trend of the Progress frame as one component. An area fill
   under a strong line, a vertical axis that fits the data with its labels, date labels along the
   bottom, the end dot. Props: `points` (each `at` and `value`), `unit`, `accessibilityLabel`,
   `testID`. It draws with `react-native-svg`, which exists. The accessibility label comes from the
   caller, because only the caller knows the numbers.
7. **The new tokens.** `emberTokens.generated.ts` now holds `type` (sixteen text styles, each with
   `size`, `lineHeight`, `weight` and `family`), `typeVar`, `radius.btn`, `size.fab`,
   `size.ringMd`, `size.ringMdStroke`, `size.ringSm`, `size.ringSmStroke`, `size.macroBar`, and the
   colors `appleHealth`, `emberTile`, `mediaScrimStrong`.
   - Make the token test cover them: `tokens.json` against `tokens.css` for every variable, not
     only the colors.
   - Move the values out of `apps/mobile/src/design/tokensWithoutSource.ts` into the chain, one by
     one, keeping every key the app uses: `appleHealth`, `radius.button`, the sizes of the floating
     button, the ring and the macro bar, and the typography scale. A key whose meaning did not
     change points at the new token. A key with no counterpart stays and is listed.
   - Expose the text styles where the components read typography, under names that follow the
     design (`type.largeTitle`, `type.body`, `type.numMd`, the same names as `tokens.json`).
   - `tokensWithoutSource.ts` keeps only what the design still has no variable for, and the test
     pins that list.
8. **`Icon`** learns `carrot`: the set holds 52 symbols now, and its test reads `index.html`.
9. **Two gaps from U-77.** `BannerNote` gains a `caution` and an `error` look, because today it
