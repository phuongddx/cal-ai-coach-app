## Deliverables

All under `apps/mobile/src/design`. Every component has a test file with behavior sentences.

1. **`Icon`**: props `name`, `size` (default 20), `color` (a token color). One name for every
   `<symbol id="i-…">` of `index.html`, path data copied verbatim, drawn with `react-native-svg`
   (15.16.0, already a dependency). With an `accessibilityLabel` the icon is an image with that
   label; without one it is decorative (`accessible={false}`), because the button or the row next
   to it carries the label. A test reads `index.html` and asserts that the names are exactly the
   symbol ids.
2. **`GlassIconButton`**: `icon`, `onPress`, `accessibilityLabel`, `testID`, and an optional
   `tone` of `'overMedia'` or `'onSurface'`. Over a photo or the camera it is the dark glass of the
   frame with a light glyph; on a surface it is the glass the canvas draws for that mode. At least
   44 by 44 pt.
3. **`SheetHeader`**: `title`, an optional `onBack` with `backAccessibilityLabel`, an optional
   `onClose` with `closeAccessibilityLabel`, `testID`. Built from `GlassIconButton`.
4. **`Segment`**: `options` (each `value` and `label`), `value`, `onChange`, `variant` of `'chips'`
   or `'text'`, `accessibilityLabel`, `testID`. `chips` is the mode row of the viewfinder (the
   selected chip is black on orange). `text` is the meal segment of the review and the
   Search / Saved / Recent row (the selected option in accent ink with the indicator the frame
   shows). Every option is a radio button with a target of at least 44 pt and the testID
   `${testID}.${value}`; the selected option announces `selected`.
5. **`EdSafeNote`**: `title`, `body`, `icon` (default the eye-off glyph), `testID`. The note card
   the frames draw on the accent tint. It renders nothing unless ED-safe mode is on. That branch
   lives here, in design (invariant I7), so no feature asks for the mode to show a note.
6. **`FillField`**: the 56 pt fill field. `label`, `value`, `onChangeText`, `unit`, `placeholder`,
   `keyboardType`, `accessibilityLabel`, `testID`. The label stays visible; it is never only a
   placeholder.
7. **`GramsRuler`**: the drag ruler of the review frame. `value`, `onChange` (whole grams), `min`,
   `max`, `step` (default 1), `majorEvery` (default 50), `accessibilityLabel`, `testID`. It has
   adjustable accessibility actions that increment and decrement by `step`, so VoiceOver changes
   the value without dragging. If it does not work in Jest after two hours, stop: leave it out of
   the barrel and describe its state in the findings.
8. **`OptionCard`** gains two optional props: `icon` (the icon tile of the frame) and a selected
   check when `selected` is true. Additive only: every caller on `main` stays as it is.
9. The barrel exports; one row per component in
   `docs/rn-migration/parity-detail/design.md`; `docs/rn-migration/findings/U-71b.md` with one
   table (component, props, the frames that use it). The restyle units quote that table.
