## Shape

- `data/health/healthKitService.ts`: the Swift API as one service with injected native calls (the
  `@kingstinct/react-native-healthkit` functions behind a small port, so Jest uses the mock):
  `requestAuthorizationIfNeeded()` asks to read steps only, and only when the status is not
  determined; `enableBackgroundDeliveryIfAuthorized()`; `todayStepCount()`; `writeBurnedEnergy(entry)`
  takes a `ConfirmedEnergyEntry` that only the confirm code can create (a branded type, as the
  parity row says); deleting a meal deletes each child sample (I12), on top of what the spike
  proved.
- `features/onboarding/healthAccess.ts`: call the service's `requestAuthorizationIfNeeded()` instead
  of asking for five types. Granted advances, denied shows the footnote, as today.
- `platform/notifications/notificationScheduler.ts`: the three reminders (`meal.lunch`,
  `meal.dinner`, `eod.recap`) are decided by `NotificationScheduler` in `@coachcal/core` and
  scheduled through `expo-notifications` behind an injected port: ask permission, remove the pending
  requests of the day and schedule again, idempotent. Export `refreshNotifications()`; the caller
  (after a local write and at launch) is a later unit: name it in the findings.
- `platform/csv/csvExportFile.ts`: `exportCsvAndShare()` writes the output of `csvExport()` to a
  file in the cache directory through `expo-file-system`, then hands the URL to `expo-sharing`.
  The settings route binds its `csvExportAction` to it.
