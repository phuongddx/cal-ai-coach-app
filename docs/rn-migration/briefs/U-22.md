## Shape

- `src/design/tokens.ts`: every token of `Tokens.swift` as `const` objects, light and dark. A hook
  `useTokens()` returns the set for the current color scheme (`useColorScheme` from `react-native`).
  Move the spike's `tokens.ts` content here (do not keep two token files) and move `format.ts` to
  `src/design/format.ts`.
- `src/design/edSafe.ts`: exports `edSafeMode()` and `edSafeHidden()` and nothing else. A Zustand
  store holds the flag (not persisted; U-51 persists it). `edSafeHidden()` returns true when ED-safe
  mode is on. Components call `edSafeHidden()`; feature code never reads the flag in any other way.
- `src/design/components/<Name>.tsx`: one RN component per CC component, same name without the `CC`
  prefix (`CCPrimaryButton` becomes `PrimaryButton`), same props and variants as the Swift type,
  same default values. Allowed packages only: `react-native`, `react-native-svg`, `expo-symbols`
  (`SymbolView` for SF Symbols), `expo-glass-effect` (`GlassView`), `react-native-reanimated` for
  animation that the Swift component has. Each component that carries a calorie framing applies the
  ED-safe policy inside itself, exactly where the Swift component does.
- `CCScaledNumber`: the Swift version scales its font with Dynamic Type; use `allowFontScaling` and
  the typography scale.
- Keep every `accessibilityIdentifier` and accessibility label identical to the Swift one. Test IDs
  in RN are the `testID` prop. List every identifier you find in `parity-detail/design.md`.
- Tests: one Jest file per component with React Native Testing Library. RNTL 14: `await render(<X />)`
  before queries. Tests live next to the component (`<Name>.test.tsx`), never under `src/app/`.

the component until it passes. Start with `PrimaryButton` so the pattern is set, then the rest.
