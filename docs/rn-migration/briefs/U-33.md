## Shape

- `features/today/todayModel.ts`: the totals of the day from the local store through injected
  readers (the diary entries and their details for today, the active target, the streak state, the
  water logs), `now`, `ownerId` (the user of the session when one exists, otherwise `DEMO_USER_ID`
  from `apps/mobile/src/data/repos/seedDataManager.ts`). The kcal rule is `@coachcal/core`. Jest
  builds it with test doubles.
- **The screen** in `features/today/TodayView.tsx`, built from `src/design` components on the design
  tokens (`useTokens`), not on `features/ember/tokens.ts`. The week strip keeps the SwiftUI colors
  (the light strip of the spike lost contrast when scrolled).
- **The Scan button (TD-01).** Place it as SwiftUI's `ScanFAB` sits in the old app, and give the
  meal list the same bottom inset the Swift view has, so no meal's kcal is ever covered. It keeps
  `testID` `shell.fab` and opens the scan route of U-30 (`router.push('/scan')`). The Diary entry
  opens the diary route of U-32.
- **ED-safe (I7).** No `edSafe` call under `features/today`: the design components own the policy.
- **Dev-only switch.** Launch arguments cannot be read on a device yet (U-51 adds a console switch in
  parallel). For the ED-safe screenshots, the Today route accepts `coachcal://?edSafe=1`, honored
  only under `__DEV__`, which calls `setEdSafeMode(true)` for the session. U-51 replaces it.
- **Identifiers.** Every `accessibilityIdentifier` of the Swift views becomes the `testID` of the
  same element (same string). Put the table in `parity-detail/today.md`.
- **Routes.** `(tabs)/index.tsx` and `(tabs)/_layout.tsx` are the only files of the feature that
  import `getDataEnvironment`, `getSessionStore`, `getDebugFlags`, `notifyLocalMutation`,
  `getSyncRuntime` and the design ED-safe setter. No tests under `src/app`.
