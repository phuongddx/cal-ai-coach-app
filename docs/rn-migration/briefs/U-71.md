## Shape

- **Tokens.** `apps/mobile/src/design/tokens.ts` holds every variable of `tokens.css`: the colors
  for light (`:root`) and dark (`.dark`), the spacing scale, the radii, the sizes, the two font
  families. A CSS name becomes a camelCase key (`--cc-accent-ink` becomes `accentInk`, `--r-md`
  becomes `radius.md`, `--s4` becomes `space.4`), in the groups the file already uses. Keep every
  key the app uses today working: a key whose meaning did not change points at the Ember value
  (the accent is now `#FF6A00`, not the lime); a key that has no Ember counterpart keeps its value
  and is listed in the findings with the unit that still uses it. Do not delete a key in this unit.
  `useTokens()` keeps following the color scheme.
- **The token test compares two files, not a table typed by hand.** The test reads
  `docs/design/ember/tokens.css`, parses `:root` and `.dark`, and asserts for every variable that
  the TypeScript token has the same value, and that every color token in TypeScript has a source in
  the CSS. Alpha values such as `rgba(20,18,16,.08)` may be stored in the format React Native
  needs; the test compares them after normalizing.
- **The color rules of `design-system.md`.** `#FF6A00` is a fill and its label is `#0B0A09`, never
  white. Orange text on a light background is `accentInk`. Orange lines, rings and bars on light are
  `accentStrong`. Caution is yellow, carbs are teal. The hero card is dark in both modes.
- **Components, as the "Component mapping" table and the frames show them.** Primary button: accent
  fill, on-accent label, 56 pt, radius 18. Secondary button: `onPress` is required (no default that
  does nothing). Destructive button on `errorTint`. Confidence badge on its own row, never
  truncated, tiers unchanged. The grams control: minus and plus of 44 pt, step 10, a tappable field,
  serving chips; the new field gets the testID `scan.grams.<id>.field` and the plus button keeps
  `scan.grams.<id>.increment`. The hero card: `ember` background with the orange glow at 30%. Cards,
  rows, rings, bars and chips take the Ember tokens and radii. Sheets: medium and large detents and
  a visible drag indicator where React Native can express them. Where `design-system.md` names a
  SwiftUI API (`ConcentricRectangle`, `.sensoryFeedback`, `.tabViewBottomAccessory`), write the
  React Native equivalent or the fallback in the findings; do not add a package.
- **Nothing else moves.** The ED-safe policy stays in `edSafe.ts` and the components (I7). The name
  and the props of every export stay, apart from added optional props. No identifier changes.
- **Tests.** A test may change only where it asserts a visual value (a color, a size, a radius). A
  behavior sentence stays. A test that passes today must pass at the end unless it asserts a visual
  value.
