## Shape

`scripts/rn/evidence/lib.sh`, sourced by every flow, with at least these functions (bail out with
`set -euo pipefail` friendly behavior: a failed expectation counts as FAIL and the flow goes on; the
run stops only when the Simulator, Metro or the app cannot be used at all):

```text
sim_boot                     boot the Simulator if it is shut down and wait until it is ready
sim_appearance light|dark
app_install_fresh           uninstall com.nextlabs.coachcal and install the built app
metro_start / metro_stop    Metro on 8081 from this worktree, log to the log directory; stop by the
                             recorded pid, never by killing every node process
metro_wait                   until curl -s localhost:8081/status answers packager-status:running
app_open                     open the dev client URL above, then dismiss the "Open in CoachCal?"
                             dialog when it is there (axe tap --label Open), then wait for a text
app_relaunch                 terminate and launch the app, wait for a text
link <url>                   xcrun simctl openurl with the same dialog handling
ui_dump                      axe describe-ui into a file, print the file name
wait_for_text <text> [sec]  poll ui_dump until the text is there; FAIL on timeout
tap_label <label>            axe tap --label
tap_xy <x> <y>               coordinates in points
type_text <text>
shot <parity-id> <name>      xcrun simctl io <udid> screenshot docs/rn-migration/evidence/<parity-id>/<name>.png
step / ok / bad / expect     as in scripts/rn/e2e-sync-app.sh; a transcript file per flow under
                             docs/rn-migration/evidence/transcripts/
finish                       print the FAIL count and exit with it
```

Flows under `scripts/rn/evidence/flows/`, each started through `run-all.sh` so that Metro and the
Simulator are handled once for all of them:

| Flow | Does | Saves |
|---|---|---|
| `01-first-launch.sh` | fresh install, open, wait for "Today" | `PL-01/01-first-launch-light.png`, then dark: `PL-01/01-first-launch-dark.png` |

| `03-today-seeded.sh` | `coachcal://debug?action=seed`, wait for the seeded meals, light and dark | `TD-01/03-today-seeded-light.png`, `TD-01/03-today-seeded-dark.png` |
