## Shape

- `apps/api/src/http.ts`: `json`, `errorJson(status, code, details?)`, `zodIssues` (dotted paths).
  Every body, success or error, goes through here.
- `apps/api/src/db.ts`: one `postgres` client from `DATABASE_URL`; `withUser(userId, fn)` opens a
  transaction, runs `SELECT set_config('app.user_id', $1, true)`, calls `fn`, commits. The ported SQL
  functions read `current_setting('app.user_id', true)::uuid` everywhere the original reads
  `auth.uid()`. The API connects as role `coachcal_api`.
- `apps/api/src/migrate.ts` and `npm run migrate` in `apps/api`: applies `apps/api/migrations/*.sql`
  in file-name order, each inside a transaction, skipping ones recorded in `schema_migrations`; run
  as role `coachcal_owner`.
- `apps/api/migrations/`: the three SQL files ported. Keep table and column names, constraints,
  indexes, comments and the five SECURITY DEFINER functions as they are; change only `auth.uid()` and
  the grants (the API role gets `EXECUTE` on the five functions and nothing on the tables; revoke
  `PUBLIC` defaults where the original relies on Supabase defaults). The sync functions
  (`sync_push`, `sync_pull`) are ported as they are but wired by U-21.
- Domain files mirroring the Deno layout: `quota.ts`, `entitlement.ts`, `routing.ts`,
  `hiddenFat.ts`, `grounding/{cascade,fdc,off,fatsecret,normalize}.ts`, `vlm/{provider,gemini,fixture}.ts`,
  `lookup/{barcode,search}.ts`, `scan/{pipeline,route}.ts`. `fetch` is injectable the way the Deno
  tests stub `fdcFetch.impl`.
- `apps/api/src/app.ts`: mount the new routes under `/v1` behind one `requireUser` middleware. In
  this unit `requireUser` accepts the checked-in dev tokens only when `AUTH_DEV_TOKENS=1` (default
  off: without it every protected route answers 401). U-21 later replaces the inside of
  `requireUser` with real session verification. Keep `registerSyncRoutes` and its tests as they are.
- Module style: write only static `import` and `export` with extensionless relative paths. No
  `require`, no `__dirname`, no `import.meta`. U-21 may switch the package to ES modules.
- `apps/api/.env.example`: every variable above plus `DATABASE_URL`, `PORT`, `AUTH_DEV_TOKENS`,
  with a one-line meaning each and no value.
- Tests: Jest twins in `apps/api/src/**/*.test.ts`, one `it(...)` per `Deno.test` with the same
  sentence. Cases that need only logic run on PGlite or plain objects. Cases that need a SQL
  function (`persist_scan`, `claim_scan_credit`) run against a real PostgreSQL 17 through
  `TEST_OWNER_URL` (role `coachcal_owner`) and `TEST_API_URL` (role `coachcal_api`). When those two
  are not set, the test file must say so loudly (`console.warn`) and skip; it must never pass
  silently. `npm run migrate` must be runnable from a test against a fresh database.
- `scripts/rn/start-api.sh`: start a throwaway PostgreSQL 17 on 5433 (binaries under
  `/opt/homebrew/opt/postgresql@17/bin`), create the two roles, run migrations as the owner, start
  the API on 8787 as `coachcal_api` with `AUTH_DEV_TOKENS=1` and `VLM_PROVIDER=fixture`, and export
  `TEST_OWNER_URL` and `TEST_API_URL` into a file other commands can source. `stop` ends both and
  frees the ports. Keep the script's current behavior for the spike's sync routes.
- `scripts/rn/smoke-scan.sh`: with the API running, `curl` `/health`, a photo scan built from
