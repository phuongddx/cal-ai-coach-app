## Goal

One source for every value, and nothing copied by hand again:
`tokens.css` gives `tokens.json`, which gives `emberTokens.generated.ts`, which gives the keys the
app uses. And the app honors the Increase Contrast setting of iOS.

## Deliverables

1. **`tokens.ts` builds its groups from `emberTokens`.** No color, space, radius, size or font value
   is written by hand in that file any more. Every key the app uses today keeps its name and its
   value, the aliases included. The three new colors are exposed where the components read colors:
   `segmentSelected`, `onMedia`, `mediaScrim`.
2. **High contrast.** `getTokens({ colorScheme, highContrast })` is a pure function. `useTokens()`
   reads the color scheme and `AccessibilityInfo.isHighContrastEnabled()`, follows
   `highContrastChanged`, and returns the colors of `highContrastLight` or `highContrastDark` when
   the system setting is on. Space, radius, size and font do not change with contrast.
3. **The token test compares the chain, not a table.**
   - `tokens.json` equals `tokens.css` for the four cascaded modes. The cascade is the one of
     `tokens-to-json.mjs`: light is `:root`; dark adds `.dark`; high contrast light adds `.hc`;
     high contrast dark adds `.dark`, `.hc` and `.dark.hc`.
   - `emberTokens.generated.ts` is what `node scripts/rn/gen-tokens.mjs --check` accepts.
   - Every color `useTokens()` returns in each of the four modes equals the value of the chain for
     that mode.
   - A key that exists today still resolves.
   - Prove once, in the findings, that one changed value fails at each link: in `tokens.css`, in
     `tokens.json` and in `tokens.ts`. Change, run, restore.
4. **The two approximations of U-71b go.** The selected pill of `Segment` uses `segmentSelected`.
   `GlassIconButton` in the tone `overMedia` uses `onMedia` for its glyph and `mediaScrim` for its
   surface.
5. **What moved.** A list in the findings of every variable whose light or dark value changed
   between `origin/main` and this branch:
   `git diff origin/main...HEAD -- docs/design/ember/tokens.css`. The owner expects none outside
   the two high-contrast blocks. If one changed, name the screens that show it.
6. **Docs.** `docs/rn-migration/parity-detail/design.md`: the rows of PL-06 and PL-07 say where
   each value comes from now. `docs/rn-migration/findings/U-71c.md`: what a unit that merged before
   this one has to do after it merges `main` (nothing, or a color that moved), the behavior under
   high contrast, the mutation proof and the list of item 5.
