## Goal

Under ED-Safe, the message of a Toast and the chip of a FoodRow are hidden whenever the text
carries a calorie word in any everyday form, with or without a number. A text that carries no
calorie word is shown exactly as today. The screen fails toward hiding.

## The rule

A text is hidden when, read without case, it contains any of these as a word, or glued to a
number before or after, or followed by punctuation:

`kcal`, `kcals`, `cal`, `cals`, `calorie`, `calories`, `kJ`, `kJs`, `kilojoule`, `kilojoules`

A text is shown when those letters are only part of a longer word. The false positive the brief
accepts, as U-71e did: a text that is only a name such as "Cal" is hidden.

Write the rule once and use it in both components. If you move it out of `Toast.tsx` into its own
module under `apps/mobile/src/design`, keep the exported name `carriesCalorieFigure` so no caller
changes, and say so in the findings.
